# Batchu Girish Kumar - Portfolio

Data Analyst • Data Science • Machine Learning

Interactive portfolio built with React, Vite, Tailwind CSS, Three.js, and Framer Motion.

## 🚀 Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
